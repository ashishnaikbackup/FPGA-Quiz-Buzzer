VERILOG · VIVADO · FPGA

Quiz Buzzer,
built in hardware.

A compact three-player quiz buzzer implemented with a finite state machine and deployed on an FPGA board using Xilinx Vivado.

View source on GitHub ↗Explore design

quiz_buzzer.v
always @(posedge clk or posedge rst)
begin
  case(state)
    S0: if(btnA) state <= S1;
        else if(btnB) state <= S2;
        else if(btnC) state <= S3;
  endcase
end

01 — OVERVIEW

Fast response.
Simple logic.

The system detects which of three players presses first, locks the corresponding state, and lights that player's LED for approximately one second before returning to the waiting state.

Created as a college FPGA/Vivado project and documented here as a clean, reproducible HDL project.
